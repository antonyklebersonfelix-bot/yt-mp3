# YT MP3

App de Mac para converter links de vídeos (YouTube, Instagram…) em MP3 e descobrir qual música um vídeo usa.

**Baixar:** veja a [última versão](../../releases/latest) e baixe `YT-MP3.zip`. Requer Mac com chip Apple.

Na primeira vez, o macOS bloqueia o app (não é da App Store): vá em Ajustes do Sistema → Privacidade e Segurança → **Abrir Mesmo Assim**. Depois disso, o app avisa e se atualiza sozinho quando houver versão nova.

Publicar versão nova: `./release.sh 1.2.0 "o que mudou"`.
